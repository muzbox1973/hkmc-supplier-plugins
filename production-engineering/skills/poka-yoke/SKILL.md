# /poka-yoke

> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

## 진행

1. **불량 이해**: 현상, 발생 공정, 발생 빈도, 지금 막는 방법(검사·주의 교육)
2. **실수 유형 분류**: 빠뜨림(누락), 잘못 고름(오품), 잘못 놓음(방향·위치), 덜 함(반삽입·체결 부족), 순서 틀림, 혼입
3. **아이디어**: 유형마다 아래 수준으로 2~4개씩 낸다
   - 발생 방지(가장 좋음): 형상으로 잘못 끼울 수 없게, 부품이 맞아야만 설비가 동작
   - 검출 후 정지: 센서·카운터·비전으로 이상 시 설비 정지
   - 검출 후 경고: 램프·부저 (가장 약함)
4. **비교표**: 효과(발생 방지/검출), 대략적 구현 난이도(상·중·하), 필요 자원, 작업 시간 영향
5. **유지 관리**: 장치 일일 작동 점검 방법(불량 샘플로 확인), 장치 고장 시 대체 검사

## 출력 형식

```markdown
## 오류방지 제안: [공정] — [불량 현상]
### 실수 유형
### 아이디어
| No | 아이디어 | 방식(방지/정지/경고) | 난이도 | 기대 효과 | 고려 사항 |
### 추천안과 이유
### 일일 점검 방법
```

## 주의

- 비용 금액은 사용자가 견적을 주지 않으면 쓰지 않고 난이도로만 표시한다.
- 와이어링 하네스의 오삽입·반삽입 문제면 `wiring-harness`의 `/harness-defect-analysis`와 함께 쓰라고 안내한다.
