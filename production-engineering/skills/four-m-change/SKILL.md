# /four-m-change

> 4M 정의는 [HKMC-FACTS.md](../../HKMC-FACTS.md) 3장을 참고한다.
> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

현대·기아 공급망에서는 협력사가 4M을 **임의로 바꿔 생산하지 않는 것**이 기본 원칙이다. 이 스킬은 변경 전에 신고·승인·검증을 빠짐없이 끝내도록 돕는다.

## 1. 변경 분류

변경 내용을 4M(+측정·환경)으로 분류하고 아래를 확인한다.

| 분류 | 예 |
|---|---|
| Man | 중요 공정 작업자·검사원 변경, 신규 작업자 투입 |
| Machine | 설비 신규·교체·이전, 설비 조건 변경, 금형·지그·애플리케이터 신작·수정 |
| Material | 원자재·구매 부품 변경, 하위 협력사 변경, 재질 변경 |
| Method | 공정 순서·작업 방법 변경, 검사 방법 변경, 생산 장소 변경(해외 이관 포함) |
| Measurement / Environment | 계측기·검사 장비 변경, 작업 환경 변경 |

## 2. 신고 대상 판단

고객사의 **변경점 관리 기준서**(신고 대상 목록, 신고 등급, 제출 서류)를 먼저 묻는다. 기준서가 있으면 그 기준으로만 판정한다.

기준서가 없으면 판정하지 않고 "신고 대상일 가능성이 높은 변경"을 근거와 함께 제시한 뒤, 고객 품질 담당에게 확인하라고 안내한다. 일반적으로 생산 장소, 설비, 하위 협력사, 재질, 공정 순서 변경은 고객 승인이 필요한 경우가 많다.

## 3. 영향·위험 분석

- 변경이 영향을 주는 제품 특성(특히 특별특성)
- PFMEA에서 해당 공정의 고장 형태가 바뀌는지
- 변경 전·후 비교 검증 방법(치수, 성능, 신뢰성 시험)
- 재고 확보: 변경 기간 중 납품 차질 방지용 선행 생산 수량

## 4. 초물 검증·유동 관리 계획

- 변경 후 첫 생산품(초물) 검사 항목과 판정자
- 변경 후 일정 기간 강화 검사(검사 빈도 상향, 기간·수량 기준은 고객 기준 우선)
- 변경 LOT 식별 표시와 추적 기록
- 이상 발생 시 원복 계획

## 5. 문서 개정

공정흐름도, PFMEA, 관리계획서, 작업표준서, 검사기준서, 설비 관리대장, 하위 협력사 목록 중 개정이 필요한 것.

```markdown

| 항목 | 내용 |
|---|---|
| 변경 분류 | Man/Machine/Material/Method |
| 변경 전 / 변경 후 | |
| 변경 사유 | |
| 적용 예정일 / 적용 LOT | |
| 고객 신고 대상 | [기준서 근거] 또는 [확인 필요] |

### 영향·위험 분석
### 검증 계획 (변경 전·후 비교)
### 초물 검증·유동 관리
### 문서 개정 목록
### 승인
| 구분 | 부서 | 성명 | 일자 |
```

## 연결 도구가 있으면

- **~~groupware**: 사내 변경 승인 결재를 기안한다.
- **~~customer portal**: 고객 변경점 신고 양식과 신고 이력을 확인한다.
- **~~MES**: 변경 전·후 공정불량을 비교한다.

## 주의

- 고객 승인 전에 변경 품을 납품하는 계획을 만들지 않는다. 승인 전 일정이 급하면 승인 일정 협의를 먼저 제안한다.
