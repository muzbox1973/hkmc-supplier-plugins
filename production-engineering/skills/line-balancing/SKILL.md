# /line-balancing

> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

## 받을 데이터

- 요구 물량(일·월), 근무 형태(교대 수, 근무 시간, 휴식·식사, 계획 정지)
- 공정별 작업 요소와 시간(초) — 측정값이면 측정 회수도
- 공정 간 선후 관계(먼저 해야 하는 작업)
- 설비 가동률·불량률 가정이 있으면 함께

## 계산 (반드시 코드로 실행)

- 가용 시간 = 근무 시간 − 휴식 − 계획 정지
- 택트타임 = 가용 시간 ÷ 요구 수량
- 이론 최소 공정 수 = 총 작업시간 ÷ 택트타임 (올림)
- 라인 밸런스 효율(%) = 총 작업시간 ÷ (공정 수 × 최대 공정시간) × 100
- 설비 CAPA = 가용 시간 × 가동률 ÷ 사이클타임 (가동률·불량률은 사용자 값만 쓰고, 없으면 100% 가정으로 계산한 뒤 표시)

## 개선안

1. 택트타임을 넘는 공정(병목)을 표시한다
2. 작업 요소 재배분안: 선후 관계를 지키면서 공정시간을 고르게 만든다
3. 재배분으로 안 되면: 병렬화(설비·작업대 추가), 작업 요소 개선(지그·자동화), 외주·서브 라인 분리
4. 개선 전·후 비교표와 산포(공정시간 막대 그래프)

## 출력 형식

```markdown
## 라인 밸런싱 분석: [라인명] — 요구 [수량]/일
| 항목 | 값 |
|---|---|
| 가용 시간 | |
| 택트타임 | |
| 현재 공정 수 / 이론 최소 | |
| 밸런스 효율 (현재 → 개선) | |

### 공정별 시간 (현재)
| 공정 | 작업 요소 | 시간(초) | 택트 대비 |
### 개선안
### 개선 후 배치
```

공정시간 막대 그래프와 택트타임 선을 함께 그린 차트를 제안한다.

## 주의

- 측정 데이터가 적으면(작업 요소당 측정 몇 회 미만) 결과의 신뢰도가 낮다고 적는다.
- 작업자 수를 줄이는 개선안에는 작업 부하·안전 검토가 필요하다고 함께 적는다.
