# /design-change

> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

## 1. 변경 내용 정리

변경 전·후 도면이나 통보서를 비교해 변경점 목록을 만든다.

| No | 위치 | 변경 전 | 변경 후 | 변경 유형(치수/재질/부품/회로/표기) |
|---|---|---|---|---|

두 도면을 모두 받지 못했으면 통보서 내용만으로 정리하고, 확인이 필요한 부분을 표시한다.

## 2. 영향 분석

변경점마다 아래 영향을 확인한다.
- **자재**: 신규 부품 품번, 조달 리드타임, 구 부품 재고·발주 잔량
- **공정**: 작업 순서, 설비 조건, 지그·조립판·검사구 수정
- **검사**: 검사 기준, 통전검사 프로그램, 한도 견본
- **문서**: 도면, BOM, 공정흐름도, PFMEA, 관리계획서, 작업표준서, 검사기준서, 포장 사양
- **승인**: 초도품(ISIR) 재제출 필요 여부 — 고객 요구를 확인 항목으로 둔다 (`/isir-package`)
- **원가**: 재료비·공수 변동 (단가 변경 협의가 필요하면 `supply-chain`의 `/cost-breakdown` 연계)

## 3. 적용 계획

- 적용 시점: 고객 지정 적용일 또는 적용 LOT, 사내 첫 적용 LOT
- 구 사양 처리: 구 재고 소진 / 폐기 / 고객 협의 (결정은 고객 승인 사항으로 둔다)
- 혼입 방지: 신·구 사양 식별 표시, 라인 전환 시 잔량 회수 확인
- 4M 변경점 신고가 동반되는지 확인 (`production-engineering`의 `/four-m-change` 연계)

## 출력 형식

```markdown
## 설계변경 적용 계획: [품번] [EO 번호] Rev.[전]→[후]
### 1. 변경점 목록
### 2. 영향 분석
| 영역 | 영향 내용 | 필요 조치 | 담당 | 기한 |
### 3. 적용 계획 (적용 시점, 구 재고, 혼입 방지)
### 4. 문서 개정 목록
| 문서 | 현재 개정 | 개정 필요 | 담당 |
### 5. 고객 확인 필요 사항
```

## 연결 도구가 있으면

- **~~ERP**: 구 부품 재고·미입고 발주 수량을 조회한다.
- **~~document storage**: 개정 대상 문서의 현재 개정번호를 확인한다.
