# /isir-package

> 용어와 국제 공통 도구(PPAP 요소·레벨)는 [HKMC-FACTS.md](../../HKMC-FACTS.md) 3장을 참고한다.
> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

현대·기아 공급망에서는 초도품 승인을 **ISIR**이라고 부른다. 이 스킬의 기본 용어와 결과물 제목은 ISIR로 쓴다. AIAG PPAP는 해외 완성차나 글로벌 고객이 요구할 때만 쓰는 보조 기준이다.

## 시작 질문

1. **고객 ISIR 서류 목록·양식**: 1차 협력사나 완성차가 지정한 목록이 있는가 (있으면 그것만 기준으로 삼는다)
2. **제출 사유**: 신규 품번 / 설계변경 / 4M 변경 / 장기 미생산 후 재생산 / 공급처 변경
3. **샘플 생산 조건**: 양산 설비·양산 작업자·양산 자재·양산 공정에서 만든 샘플인가
4. **고객 종류**: 현대·기아 공급망(ISIR) / 해외 고객(PPAP 요구 여부와 제출 레벨)

1차 협력사마다 ISIR 서류 구성과 양식이 다를 수 있다. 고객 목록이 없으면 아래 기본 점검 틀로 진행하되, "고객 서류 목록 미확인"이라고 결과물에 적는다.

## 기본 점검 틀 (고객 목록이 없을 때)

| 묶음 | 확인할 서류 |
|---|---|
| 설계 근거 | 최신 도면·사양서, 설계변경 이력 |
| 치수 | 도면 전 치수(풍선 번호) 측정 성적서 |
| 재질·성능 | 재질 성적서, 고객 규격 기준 성능·신뢰성 시험 성적서, 시험기관 자격 증빙 |
| 공정 | 공정흐름도, PFMEA, 관리계획서, 작업표준서 |
| 공정 능력·측정 | 특별특성 공정능력(Cpk/Ppk), MSA |
| 외관·샘플 | 외관 검사 결과, 한도 견본, 초도품 샘플 |
| 포장·표시 | 포장 사양, 라벨 |
| 하위 부품 | 구매 부품 승인·성적서 (커넥터·단자 등) |

## 작업

### 1. 체크리스트
서류마다 **필요 여부 / 보유 / 최신 개정 일치 / 담당**을 표로 만든다. 특히 아래 연결을 확인한다.
- 도면 개정번호 = 치수 성적서 기준 도면 = ISIR 표지 기재 개정번호
- 공정흐름도 ↔ PFMEA ↔ 관리계획서 공정번호 일치
- 특별특성이 관리계획서와 공정능력 자료에 모두 있는가
- 치수 성적서가 도면의 모든 치수를 덮는가
- 시험 성적서의 규격 번호·시험 조건이 고객 규격과 같은가

### 2. 성적서 요약
사용자가 준 측정·시험 데이터로 합격/불합격과 공정능력 지수를 **코드로 계산**해 요약한다. 공정능력 요구 수준 같은 기준값은 고객 문서에서만 가져온다.

### 3. 반려·조건부 승인 대응
고객 판정이 반려나 조건부 승인이면 사유별로 원인, 조치, 재제출 일정, 조건부 기간의 관리 방법을 표로 만든다.

### 4. 해외 고객 PPAP (요구 시에만)
AIAG PPAP 18개 요소와 고객 지정 제출 레벨(1~5)로 같은 체크리스트를 다시 만들고, PSW(부품 제출 보증서) 초안을 작성한다.

## 출력 형식

```markdown
## ISIR 제출 점검: [품번] [품명] Rev.[ ] — 제출 사유 [ ]
**기준:** [고객 ISIR 서류 목록·버전 또는 "기본 점검 틀(고객 목록 미확인)"]

| No | 서류 | 필요 | 보유 | 개정 일치 | 문제 | 담당 |
|---|---|---|---|---|---|---|

### 누락·불일치 항목
### 성적서 요약
### (해당 시) 반려 대응 / PPAP·PSW
```

## 연결 도구가 있으면

- **~~document storage**: 각 서류의 최신 개정본을 찾아 개정번호 일치를 점검한다.
- **~~customer portal**: ISIR 서류 양식, 제출 이력, 승인 판정을 확인한다.

## 주의

- 측정값이 없는 항목을 합격으로 채우지 않는다.
- 와이어링 하네스 품번이면 `wiring-harness` 플러그인의 압착 성적·통전검사 결과도 첨부 대상인지 확인한다.
