# /certification-audit

> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

## 시작 질문

1. 인증 종류(IATF 16949 / ISO 9001 / ISO 14001 / ISO 45001, 통합 여부)
2. 심사 종류(최초 / 사후 / 갱신 / 내부심사)와 일정, 심사 범위(사업장·공정)
3. 지난 심사 부적합·관찰 사항과 조치 상태
4. 고객 특정 요구사항(CSR) 문서 보유 여부 — IATF 16949는 CSR 준수도 심사 대상이다

## 작업

### 1. 조항별 증빙 매핑
인증 규격의 조항 구조(4장 조직 상황 ~ 10장 개선)에 맞춰 "요구사항 요지 → 회사 문서·기록 → 보관 위치 → 최신화 여부" 표를 만든다. 규격 원문은 저작권이 있으므로 조항 번호와 요지만 쓰고 원문을 길게 옮기지 않는다.

통합 심사면 공통 조항(문서화된 정보, 내부심사, 경영검토, 시정조치)을 한 번에 묶고, 규격별 고유 항목만 따로 표시한다.

### 2. 내부심사
- 심사 계획: 프로세스별 심사 일정, 심사원 독립성(자기 업무 심사 금지) 확인
- 프로세스 심사 체크리스트: 입력·출력·자원·방법·성과지표(거북이 다이어그램 방식)
- IATF는 제조공정 심사와 제품 심사도 계획에 포함한다

### 3. 경영검토 보고서
입력 항목(고객 만족, 품질 목표 달성, 프로세스 성과, 심사 결과, 시정조치, 리스크·기회, 자원, 개선 기회)과 출력(결정·조치)을 표로 만든다. 수치는 사용자 데이터로만 채운다.

### 4. 부적합 회신
심사 부적합마다: 부적합 내용 → 원인 분석 → 시정 → 시정조치 → 효과성 확인 계획 → 증빙. 수평 전개 범위를 포함한다.

## 출력

요청에 맞는 문서 하나를 마크다운으로 먼저 만들고, 필요하면 Excel(체크리스트)·Word(보고서)로 바꾸자고 제안한다.

## 주의

- 인증 규격의 개정판·전환 일정은 바뀔 수 있으므로 인증기관 공지로 확인하라고 적는다.
- 증빙이 없으면 "없음"으로 표시하고 작성 계획을 제안한다. 존재한다고 가정하지 않는다.
