# /sq-audit-prep

> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.
> 제도 관련 수치는 [HKMC-FACTS.md](../../HKMC-FACTS.md)를 근거로 하며, 반드시 기준 시점과 함께 인용한다.

SQ 인증 심사를 앞둔 협력사가 **무엇이 부족한지 알고, 증빙을 갖추고, 당일 대응할 수 있게** 만든다.

## 시작 전에 확인할 것

다음 정보가 없으면 한 번에 묻는다.
1. **업종**: SQ 12개 업종 중 해당 업종 (와이어링, 전기전자, 사출금형 등)
2. **심사 종류**: 신규 / 갱신 / 재심사(육성 후)
3. **심사 일정과 주관**: 심사일, 심사 주관(1차 협력사·고객사·위탁기관)
4. **받은 자료**: 고객사가 배포한 최신 SQ 평가 기준서·체크리스트가 있는지

> 고객사가 배포한 최신 SQ 체크리스트가 있으면 그것을 **유일한 기준**으로 삼는다. 아래 자가진단 틀은 체크리스트가 없을 때 쓰는 보조 도구이며, 공식 SQ 평가표가 아님을 결과물에 명시한다.

## 작업 순서

### 1. 기준 확정
- 첨부된 공식 체크리스트가 있으면 항목·배점·과락 조건을 표로 옮긴다.
- 없으면 아래 7개 영역 자가진단 틀을 쓰고, "공식 배점 미확인"이라고 적는다.

### 2. 자가진단 (공식 체크리스트가 없을 때의 틀)

| 영역 | 확인할 증빙 |
|---|---|
| 품질경영 체계 | 품질방침·목표, 조직도, 내부심사·경영검토 기록, 문서·기록 관리 규정 |
| 개발·변경 관리 | 초도품 승인 기록, 4M 변경점 신고·승인 대장, 설계변경 적용 기록 |
| 공정 관리 | 공정흐름도, PFMEA, 관리계획서, 작업표준서, 초·중·종물 검사 기록, 셋업 검증 기록 |
| 검사·시험 | 수입·공정·출하 검사 기준서, 한도 견본, 신뢰성·기능 시험 기록 |
| 설비·계측기 | 설비 예방보전 계획·실적, 지그·금형·애플리케이터 관리대장, 계측기 교정 성적서, MSA |
| 부적합 관리 | 부적합품 식별·격리 구역, 불량 처리 기록, 8D·재발방지 대책, 클레임 대응 이력 |
| 하위 협력사·자재 | 하위 협력사 평가, 수입검사, 로트 추적(LOT 이력), 보관 조건 |
| 인적 자원 | 작업자 자격 인증(숙련도) 기록, 교육 계획·실적, 다기능 현황표 |
| 현장 관리 | 3정5S, 식별 표시, 선입선출, ESD(전장 업종) |

업종이 **와이어링**이면 `wiring-harness` 플러그인의 압착 품질·통전검사 항목을 함께 점검하라고 안내한다.

### 3. 갭 리포트
각 항목을 **충족 / 부분 충족 / 미흡 / 증빙 없음**으로 판정한다. 판정 근거는 사용자가 준 자료나 답변에서만 가져오고, 근거가 없으면 "확인 필요"로 둔다.

### 4. 개선 계획
미흡 항목마다 조치 내용, 담당, 완료 목표일, 완료 증빙을 정한다. 심사일까지 남은 기간으로 우선순위를 매긴다(과락 가능 항목 → 배점 큰 항목 → 나머지).

### 5. 심사 당일 대응 계획
- 심사 동선(사무실 → 수입검사 → 공정 순서 → 출하)과 설명 담당자
- 예상 질문과 답변 담당, 즉시 제시할 증빙 파일 위치
- 현장 점검 전날 체크(식별표, 부적합품 구역, 계측기 교정 라벨, 작업표준서 게시)

## 출력 형식

```markdown
## SQ 심사 준비 보고서: [회사/사업장] — [업종]
**심사 종류:** [신규/갱신/재심사] | **심사일:** [날짜] | **기준:** [공식 체크리스트 버전 또는 "자가진단 틀(공식 아님)"]

### 1. 요약
- 미흡 [n]건, 부분 충족 [n]건, 증빙 없음 [n]건
- 가장 시급한 3가지: …

### 2. 영역별 갭
| 영역 | 항목 | 판정 | 근거 | 필요한 조치 |
|---|---|---|---|---|

### 3. 개선 계획
| 우선순위 | 조치 | 담당 | 목표일 | 완료 증빙 |
|---|---|---|---|---|

### 4. 증빙 목록 (심사장 비치)
| 증빙 | 보관 위치 | 최신화 여부 |
|---|---|---|

### 5. 당일 대응 계획
…

> 제도 수치 출처: HKMC-FACTS.md (공개 자료 기준 시점 표기). 최신 SQ 기준서로 재확인 필요.
```

## 연결 도구가 있으면

- **~~document storage**: 증빙 파일 존재 여부와 최종 수정일을 직접 확인한다.
- **~~MES**: 최근 공정불량률·초물 검사 기록을 뽑아 공정 관리 영역 판정에 쓴다.
- **~~groupware**: 개선 계획을 전자결재 보고용 기안문으로 바꾼다(`office-workflow`의 `/approval-draft` 연계).

## 주의

- 합격 점수, 재심사 구간, 심사 기간은 공개 기사 기준이다. 결과물에 수치를 쓸 때 기준 시점을 반드시 함께 적는다.
- 증빙이 없는데 "있다"고 가정해 충족 판정하지 않는다.
