# /harness-process-flow

> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

## 받을 정보

- 품번의 회로도·BOM(전선 수, 단자·커넥터 종류, 스플라이스 수, 보호재)
- 사내 보유 설비(자동 절단·압착기, 초음파 융착기, 통전검사기 등)
- 공정 순서가 정해져 있으면 그 순서

## 기본 공정 틀 (품번에 맞게 고친다)

| 공정 | 주요 관리 항목 | 대표 고장 형태 |
|---|---|---|
| 자재 입고·수입검사 | 전선·단자·커넥터 품번, LOT | 오자재, 손상 자재 |
| 절단·탈피 | 절단 길이, 탈피 길이, 소선 손상 | 길이 불량, 소선 절단·흠집, 탈피 불량 |
| 압착 | 크림프 하이트·폭, 인장력, CFM | 압착 불량, 피복 물림, 오단자 |
| 스플라이스(융착·압착) | 접합 강도, 위치, 절연 처리 | 접합 불량, 위치 불량, 절연 누락 |
| 서브조립·트위스트 | 회로 조합, 꼬임 피치 | 회로 누락, 피치 불량 |
| 커넥터 삽입 | 캐비티 위치, 단자 로킹, 리테이너 | 오삽입, 반삽입, 리테이너 미체결 |
| 본조립(조립판) | 분기 위치, 경로, 클립·그로밋 | 경로 이탈, 클립 누락, 분기 치수 불량 |
| 테이핑·튜브·보호재 | 감김 방식, 범위, 보호재 위치 | 범위 부족, 보호재 누락 |
| 통전검사 | 회로 도통·단락, 커넥터 결합 | 단선, 단락, 오배선 미검출 |
| 외관·치수 검사 | 분기 길이, 부품 위치, 라벨 | 치수 불량, 라벨 오류 |
| 포장·출하 | 포장 사양, 수량, 라벨 | 혼입, 수량 오류, 운송 손상 |

## 작업

1. 품번 정보로 공정 순서를 확정하고, 품번에 없는 공정은 빼고 있는 특수 공정(방수 씰, 실드 처리, 고전압 부품 등)은 넣는다
2. 공정흐름도: 공정번호, 공정명, 설비, 입력·출력, 검사 공정 표시, 재작업 흐름
3. 공정별 관리 항목·고장 형태 표 (특별특성 표시는 고객 도면 기준)
4. 다음 단계로 `supplier-quality`의 `/pfmea-control-plan`에 이 표를 넘길 수 있다고 안내한다

## 출력

- 공정흐름도: 표 + (요청 시) 흐름도 그림
- 공정별 관리 항목·고장 형태 표

## 주의

- 고전압(EV) 하네스는 절연·차폐·고전압 표시 요구가 고객 규격에 따로 있으므로 해당 규격 확인을 확인 항목으로 둔다.
