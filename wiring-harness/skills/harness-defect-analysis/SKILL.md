# /harness-defect-analysis

> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

## 1. 데이터 분석 (데이터가 있을 때, 코드로 실행)

불량 실적(일자, 품번, 공정, 불량 유형, 회로·캐비티 번호, 작업자/조, 수량)을 받으면:
- 유형별 파레토
- 같은 회로·같은 캐비티 반복 여부 (특정 위치 반복이면 지그·표시·형상 원인 의심)
- 작업자·조·시간대·요일별 편차 (특정 사람·시간대 집중이면 교육·피로·교대 인수인계 의심)
- 품번·신규 투입 시점과의 관계 (설계변경·신규 품번 직후 증가 여부)

## 2. 유형별 원인 후보와 확인 방법

| 유형 | 발생 원인 후보 | 확인 방법 |
|---|---|---|
| 오삽입(다른 캐비티) | 캐비티 번호 식별 어려움, 유사 전선색, 작업 순서 표준 미흡, 지그 표시 오류 | 작업 관찰, 표시와 도면 대조 |
| 반삽입·로킹 불량 | 삽입 후 당김 확인 누락, 단자 랜스 변형, 커넥터 하우징 불량 | 단자 랜스 상태, 하우징 LOT, 작업 표준 |
| 리테이너 미체결 | 체결 확인 방법 없음, 리테이너 부품 불량 | 체결 상태 검출 여부 |
| 단선 | 압착 불량, 조립 중 과도한 당김, 절단 길이 부족 | 단선 위치, 압착 기록 |
| 단락 | 피복 손상, 스플라이스 절연 불량, 이물 | 손상 위치, 공정 이력 |
| 경로 이탈·치수 불량 | 조립판 지그 마모·위치 오류, 도면 개정 미반영 | 조립판과 최신 도면 대조 |
| 클립·부품 누락 | 부품 공급 방식, 확인 수단 없음 | 부품 공급 위치·수량 관리 |

## 3. 유출 원인

불량이 통전검사·외관검사를 통과한 경우:
- 통전검사기가 해당 불량을 검출할 수 있는 방식인가 (예: 반삽입은 도통만으로 검출되지 않을 수 있음 → 커넥터 결합·로킹 검출 방식 확인)
- 검사 프로그램이 최신 회로도로 갱신되었는가
- 검사 지그 접촉 핀 마모

## 4. 대책 방향

사람 주의에 기대는 대책보다 오류방지(`production-engineering`의 `/poka-yoke`), 검사 방식 보강, 지그·표시 개선을 우선 제안한다.

## 출력 형식

```markdown
## 하네스 불량 분석: [품번/라인] — [기간]
### 1. 데이터 요약 (파레토, 집중 위치·시간)
### 2. 원인 후보와 확인 계획
| 후보 | 근거 | 확인 방법 | 담당 | 결과 |
### 3. 유출 원인
### 4. 대책 제안
```

고객 클레임 건이면 결과를 `supplier-quality`의 `/eight-d-report`로 이어 쓰자고 안내한다.
