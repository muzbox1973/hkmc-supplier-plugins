# /machine-allocation

> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

## 받을 데이터

- 기간 생산 계획: 회로(전선 길이·규격, 양 끝 단자)별 수량
- 호기 목록: 가용 시간, 장착 가능한 애플리케이터 수, 호기별 특성(대응 전선 규격 범위 등)
- 애플리케이터 목록: 관리번호, 대응 단자, 현재 장착 호기, 수량(같은 단자용 보유 대수)
- 사이클타임(회로당), 애플리케이터 교체 시간, 전선 교체 시간

빠진 값은 가정으로 채우지 않고 묻는다. 사용자가 가정으로 진행하라고 하면 가정값을 표로 분리한다.

## 계산 방법 (코드로 실행)

1. 회로를 필요한 단자 조합으로 묶는다(같은 애플리케이터 조합끼리)
2. 묶음을 호기에 배정한다. 목표 순서:
   - 제약 위반 없음(호기 대응 범위, 애플리케이터 보유 대수)
   - 각 호기 부하 ≤ 가용 시간
   - 셋업(애플리케이터 교체) 횟수 최소
   - 호기 간 부하 편차 최소
3. 소규모 문제는 정수계획(예: Python PuLP 또는 OR-Tools)로 풀고, 크면 탐욕 배정 후 개선(교환 탐색)으로 풀며 어떤 방법을 썼는지 적는다
4. 현재 배분과 비교: 셋업 횟수, 최대 부하율, 부하 편차

## 출력 형식

```markdown
## 호기 배분안: [기간]
| 지표 | 현재 | 제안 |
|---|---|---|
| 총 셋업 횟수 | | |
| 최대 호기 부하율 | | |
| 호기 간 부하 편차 | | |

### 호기별 배분
| 호기 | 애플리케이터 | 회로 묶음 | 수량 | 부하(분) | 부하율 |

### 애플리케이터 이동 목록
| 애플리케이터 | 현재 호기 | 이동 호기 | 이유 |

### 가정·제약
```

배분표는 Excel로 만들어 현장 배포용으로 쓸 수 있다고 제안한다.
