# 압착 품질 점검 항목 (일반 개념)

> 이 문서는 점검 **항목**만 정리한다. 합격 **기준값**은 단자 제조사 압착 사양서와 고객 규격을 따른다.

## 1. 치수 측정
- **크림프 하이트(C/H)**: 전선 압착부(컨덕터 크림프) 높이. 마이크로미터의 압착 전용 측정자로 측정한다
- **크림프 폭(C/W)**: 압착부 폭
- **절연 피복 압착부(인슐레이션 크림프)**: 높이·폭, 피복 고정 상태
- 측정 시점: 셋업 초물, 정해진 주기, 애플리케이터·전선 LOT·단자 릴 교체 후, 정지 후 재가동

## 2. 인장력 (Pull-out force)
- 압착된 전선을 축 방향으로 당겨 단자에서 빠지거나 끊어지는 힘
- 절연 피복 압착부의 영향을 배제하는 방법(피복 압착부 해제 등)은 해당 규격의 시험 방법을 따른다
- 파단 위치 기록: 압착부 빠짐 / 압착부 내 소선 끊김 / 전선 본체 끊김

## 3. 단면 분석 (Cross-section)
- 소선 충진 상태: 빈 공간(보이드) 크기와 분포
- 압축률: 압착 전후 도체 단면적 비율 (기준은 사양서)
- 대칭성: 좌우 배럴 끝 위치, 배럴 끝이 바닥에 닿지 않았는지
- 버(burr): 배럴 하부 돌출
- 배럴 끝이 소선을 파고들거나 소선이 배럴 밖으로 나오지 않았는지
- 단자 바닥·측벽 균열

## 4. 외관
- 벨마우스(진입부 나팔 형상) 유무와 길이
- 컨덕터 브러시(소선이 압착부 앞으로 나온 길이)
- 피복이 컨덕터 압착부에 물리지 않았는지, 피복 끝 위치
- 소선 빠짐(압착부 밖으로 남은 소선), 소선 절단
- 단자 변형(굽힘, 비틀림, 캐리어 컷 잔여)

## 5. 압착력 모니터 (CFM)
- 압착 시 힘 파형을 기준 파형과 비교해 이상(소선 누락, 피복 물림, 단자 없음 등)을 검출
- 셋업 시 기준 학습, 알람 한도 설정, 알람 발생 시 제품 격리 규칙
- CFM은 모든 불량을 잡지 못하므로 주기 측정과 병행한다

## 6. 변화점
- 애플리케이터 교체·수리, 단자 릴 LOT, 전선 LOT, 압착기 정비 후에는 초물 검사를 다시 한다
- 애플리케이터 누적 타수와 마모 부품 교체 기록을 남긴다

## 참고 공개 규격
- SAE/USCAR-21: 전선-단자 압착 성능 규격 (시험 방법 참고용, 고객 규격이 우선)
