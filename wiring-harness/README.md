# 와이어링 하네스 플러그인 (`wiring-harness`)

와이어링 하네스 제조 특화 — 단자 압착 품질(크림프 하이트·인장력·단면 분석·CFM), 공정흐름도와 공정별 고장 형태, 통전·오삽입 불량 분석, 도면↔BOM 대조, 압착기 호기·애플리케이터 배분.

SQ 인증 12개 업종 중 '와이어링' 업종 협력사의 현장 기술 업무를 돕는다.

> 현대자동차·기아와 무관한 비공식 플러그인이다. 제도 관련 수치는 [HKMC-FACTS.md](HKMC-FACTS.md)의 공개 자료(기준 시점 표기)를 근거로 하며, 고객사가 배포한 최신 기준서가 항상 우선한다.

## 설치

```bash
claude plugin marketplace add <이 저장소 경로 또는 GitHub 주소>
claude plugin install wiring-harness@hkmc-supplier-plugins
```

Claude 데스크톱 앱에서는 플러그인 메뉴에서 이 폴더(또는 압축 파일)를 추가한다.

## 스킬

| 명령 | 하는 일 |
|---|---|
| `/crimp-quality` | 와이어링 하네스 단자 압착 품질을 관리한다. |
| `/harness-bom-check` | 하네스 회로도·도면과 BOM·회로 리스트(전선 리스트)를 대조해 전선 규격·색상·길이, 단자·커넥터·씰 품번, 캐비티 배정, 스플라이스, 보호재 수량의 불일치를 찾는다. |
| `/harness-defect-analysis` | 와이어링 하네스 불량(통전검사 단선·단락·오배선, 커넥터 오삽입·반삽입, 리테이너 미체결, 경로 이탈, 치수 불량, 피복 손상, 클립 누락 등)의 원인을 분석한다. |
| `/harness-process-flow` | 와이어링 하네스 품번의 공정흐름도를 만들고 공정별 관리 항목·고장 형태를 정리한다. |
| `/machine-allocation` | 절단·압착 공정에서 압착기(호기)별로 생산 품번·회로와 애플리케이터를 배분해 셋업(교체) 횟수와 부하 편차를 줄이는 계획을 만든다. |

스킬은 관련 요청을 하면 자동으로 쓰이고, 명령(`/wiring-harness:스킬이름`)으로 직접 부를 수도 있다.

## 연결 도구

연결 없이 파일 첨부와 대화만으로 작동한다. 그룹웨어·MES·ERP·고객 포털을 연결하면 자료를 직접 가져온다. 자리표시자(`~~groupware` 등)의 뜻은 [CONNECTORS.md](CONNECTORS.md)를 본다. 회사 시스템 이름으로 바꾸려면 `supplier-plugin-builder` 플러그인의 `/customize-for-company`를 쓴다.

## 공통 원칙

- 규격값·기준값은 고객 도면·규격·사양서와 회사 기준에서만 가져오고, 없으면 "확인 필요"로 남긴다.
- 계산은 코드로 실행해 검산한다.
- 고객 도면·단가·개인정보는 회사 정보보안 규정이 허용하는 범위에서만 첨부한다.
