# 안전·환경 플러그인 (`ehs-compliance`)

안전·보건·환경 업무 — 산업안전보건법 위험성평가, 중대재해처벌법 안전보건관리체계 이행 점검, ISO 14001 환경측면·법규 대장, 재해·아차사고 조사 보고서.

ISO 45001·ISO 14001을 운영하는 제조 사업장의 안전환경 문서 업무를 돕는다. 법률 자문이 아니며 최신 법령 확인을 전제로 한다.

> 현대자동차·기아와 무관한 비공식 플러그인이다. 제도 관련 수치는 [HKMC-FACTS.md](HKMC-FACTS.md)의 공개 자료(기준 시점 표기)를 근거로 하며, 고객사가 배포한 최신 기준서가 항상 우선한다.

## 설치

```bash
claude plugin marketplace add <이 저장소 경로 또는 GitHub 주소>
claude plugin install ehs-compliance@hkmc-supplier-plugins
```

Claude 데스크톱 앱에서는 플러그인 메뉴에서 이 폴더(또는 압축 파일)를 추가한다.

## 스킬

| 명령 | 하는 일 |
|---|---|
| `/env-aspects` | ISO 14001 환경경영 실무를 돕는다. |
| `/incident-report` | 산업재해·아차사고 발생 시 조사 보고서를 만든다. |
| `/osh-risk-assessment` | 산업안전보건법에 따른 사업장 위험성평가를 진행한다. |
| `/serious-accident-act` | 중대재해처벌법상 경영책임자의 안전보건 확보 의무 이행 상태를 점검한다. |

스킬은 관련 요청을 하면 자동으로 쓰이고, 명령(`/ehs-compliance:스킬이름`)으로 직접 부를 수도 있다.

## 연결 도구

연결 없이 파일 첨부와 대화만으로 작동한다. 그룹웨어·MES·ERP·고객 포털을 연결하면 자료를 직접 가져온다. 자리표시자(`~~groupware` 등)의 뜻은 [CONNECTORS.md](CONNECTORS.md)를 본다. 회사 시스템 이름으로 바꾸려면 `supplier-plugin-builder` 플러그인의 `/customize-for-company`를 쓴다.

## 공통 원칙

- 규격값·기준값은 고객 도면·규격·사양서와 회사 기준에서만 가져오고, 없으면 "확인 필요"로 남긴다.
- 계산은 코드로 실행해 검산한다.
- 고객 도면·단가·개인정보는 회사 정보보안 규정이 허용하는 범위에서만 첨부한다.
