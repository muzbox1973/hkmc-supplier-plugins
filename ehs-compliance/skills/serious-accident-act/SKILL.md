# /serious-accident-act

> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

## 법령 확인 원칙

이 스킬은 법률 자문이 아니다. 결과물 첫머리에 다음을 적는다:
"중대재해 처벌 등에 관한 법률과 시행령은 개정될 수 있으므로 국가법령정보센터(law.go.kr)의 최신 조문과 고용노동부 해설서로 확인하고, 법적 판단은 전문가와 상의할 것."

## 점검 틀

시행령의 안전보건관리체계 구축·이행 조치(제4조) 요지를 기준으로 항목을 만든다. 조문을 사용자가 첨부하면 그 원문 항목으로 바꾼다.

| 영역 | 확인할 이행 증빙 |
|---|---|
| 안전·보건 목표와 경영방침 | 방침 문서, 게시·공유 기록 |
| 전담 조직 | 조직도, 대상 여부 판단 근거(사업장 규모) |
| 유해·위험요인 확인·개선 절차 | 위험성평가 절차와 실시 기록, 정기 점검 기록 |
| 재해 예방 예산 | 예산 편성·집행 내역 |
| 안전보건관리책임자 등 권한·평가 | 권한 부여 문서, 업무 수행 평가 기준과 평가 기록 |
| 안전·보건 전문인력 배치 | 선임 현황, 업무 시간 보장 |
| 종사자 의견 청취 | 청취 절차, 개선 반영 기록 |
| 비상 대응 매뉴얼 | 매뉴얼, 훈련 기록 |
| 도급·용역·위탁 관리 | 수급인 평가 기준·절차와 평가 기록 |
| 관계 법령 의무 이행 점검 | 점검 결과, 미이행 시 조치 기록, 안전보건 교육 실시 확인 |

점검 주기(반기 등)는 조문에서 확인해 적는다.

## 작업

1. 항목별로 **이행 / 일부 이행 / 미이행 / 증빙 없음** 판정 (사용자 자료 근거로만)
2. 미흡 항목 개선 계획(조치, 담당, 기한, 증빙)
3. 경영책임자 보고 자료: 1쪽 요약(판정 현황, 위험 항목, 필요한 결정과 예산)

## 출력 형식

```markdown
## 안전보건관리체계 이행 점검: [사업장] — [점검 기간]
> 법령 확인 원칙 문구

| 영역 | 판정 | 근거·증빙 | 미흡 내용 | 조치 | 담당 | 기한 |
### 경영책임자 보고 요약
```

## 주의

- 해외 사업장(중국·베트남·멕시코·인도 등)에는 이 법이 아니라 현지 법령이 적용되므로 현지 기준 확인 항목으로 따로 분리한다.
