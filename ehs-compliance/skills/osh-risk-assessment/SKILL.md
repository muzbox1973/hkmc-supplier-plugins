# /osh-risk-assessment

> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

## 법령 확인 원칙

위험성평가 방법과 시기는 고용노동부 고시 「사업장 위험성평가에 관한 지침」을 따른다. 고시는 개정되므로 결과물 첫머리에 "최신 고시 확인 필요(국가법령정보센터 law.go.kr)"를 적고, 회사가 정한 평가 기법이 있으면 그것을 쓴다.

## 진행 단계

1. **사전 준비**: 평가 대상(공정·작업·설비), 평가 팀(관리감독자, 근로자 참여), 평가 시기(최초·수시·정기·상시)
2. **유해·위험요인 파악**: 작업 단계별로 기계적(끼임·베임·충돌), 전기적(감전), 화학적, 작업 환경(소음·분진·온열), 인간공학(반복 동작·중량물·부적합 자세), 화재·폭발 요인. 아차사고·재해 이력을 반영한다
3. **위험성 결정**: 회사 기법으로 판정. 빈도·강도법이면 회사 척도(예: 3×3, 5×5)와 허용 기준을 묻고 쓴다
4. **감소대책**: 우선순위 — 제거·대체 → 공학적 대책(방호장치, 인터록, 국소배기) → 관리적 대책(작업 절차, 교육) → 개인 보호구. 대책 후 잔여 위험성 재판정
5. **공유**: 작업 전 안전점검 회의(TBM)용 1쪽 요약
6. **기록**: 평가표 보관 (보존 기간은 고시 확인)

## 하네스·부품 제조 공정에서 자주 보는 요인 예

- 절단·압착기: 압착부 손 끼임, 절단 칼날 베임 → 방호 커버·양수 조작·인터록 확인
- 초음파 융착기: 끼임, 소음
- 조립판 작업: 반복 동작·장시간 서 있기, 테이핑 손목 부담
- 지게차·대차 운반: 충돌·협착
- 열수축 튜브 가열: 화상

(요인 예시는 출발점일 뿐이며 실제 현장 관찰로 확인한다)

## 출력 형식

```markdown
## 위험성평가표: [공정/작업] — [평가 종류] [일자]
> 최신 고시 확인 필요 (law.go.kr)

| No | 작업 단계 | 유해·위험요인 | 재해 형태 | 현재 안전조치 | 위험성(전) | 감소대책 | 위험성(후) | 담당 | 완료일 |
|---|---|---|---|---|---|---|---|---|---|

### TBM 공유 요약
### 평가 참여자
```

## 연결 도구가 있으면

- **~~document storage**: 이전 평가표와 아차사고 기록을 찾는다.
- **~~groupware**: 평가 결과 공유 공지와 결재를 기안한다.
