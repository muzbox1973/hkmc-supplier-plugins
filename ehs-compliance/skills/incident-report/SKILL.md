# /incident-report

> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

## 원칙

- 사실(시간, 장소, 작업, 관련 설비, 피해)과 추정을 구분한다. 확인되지 않은 내용은 "확인 중"으로 둔다.
- 개인을 비난하는 원인("부주의") 대신 작업 조건·설비·관리 체계 원인까지 분석한다.
- 피해자 개인정보와 상해 상세는 사내 공유본에서 빼고 필요한 최소한만 쓴다.

## 법정 보고 확인

산업재해 보고 의무(대상 재해, 보고 기한, 보고처)는 산업안전보건법령에 따른다. 결과물에 "법정 보고 대상 여부와 기한을 최신 법령으로 확인할 것"을 확인 항목으로 넣는다. 중대재해에 해당할 수 있으면 즉시 보고·작업 중지 관련 의무를 확인하라고 맨 위에 표시한다.

## 보고서 구성

1. 개요: 일시, 장소, 작업, 재해 형태, 피해 정도(사내 공유본은 요약)
2. 발생 경위: 시간 순서
3. 원인 분석: 직접 원인(불안전 상태·불안전 행동) → 근본 원인(5Why, 관리 체계)
4. 즉시 조치
5. 재발 방지 대책: 공학적 대책 우선, 담당·기한
6. 수평 전개: 같은 설비·같은 작업이 있는 라인·사업장
7. 위험성평가 개정 필요 여부 (`/osh-risk-assessment` 연계)

## 출력

- 내부 조사 보고서 (전체)
- 사내 공유용 1쪽 요약 (개인정보 제외, 교훈 중심)
