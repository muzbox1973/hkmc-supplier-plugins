# /supplier-esg

> 현대자동차 공급망 ESG 공개 내용은 [HKMC-FACTS.md](../../HKMC-FACTS.md) 5장을 참고한다.
> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

## 원칙

- 설문 답변은 **사실과 증빙이 있는 것만** "예"로 쓴다. 증빙이 없으면 "아니오" 또는 "계획 중"으로 쓰고 개선계획을 붙인다. 평가를 잘 받으려고 사실과 다른 답을 만들지 않는다.
- 받은 설문·요청서의 질문 문구와 순서를 그대로 따른다.

## 작업

### 1. 요청 정리
요청 주체(고객사명, 1차 협력사 경유 여부), 회신 기한, 설문 영역(환경, 노동·인권, 안전보건, 윤리·공정거래, 경영체계, 하위 공급망)을 정리한다.

### 2. 답변 초안
질문마다 다음 표를 만든다.

| 질문 | 답변 | 근거(회사 실제 제도·기록) | 증빙 파일 | 보완 필요 |
|---|---|---|---|---|

회사 정보가 없으면 질문 목록을 담당 부서별(인사·안전환경·구매·재무)로 나눈 확인 요청서를 먼저 만든다.

### 3. 증빙 목록
방침·규정(윤리강령, 인권·노동 정책, 안전보건 방침, 환경 방침), 인증서(ISO 14001, ISO 45001 등), 교육 기록, 에너지·온실가스·폐기물 데이터, 하위 협력사 전달 기록.

### 4. 개선계획서 (고위험·미흡 판정 시)
항목별 현재 상태 → 개선 목표 → 조치 → 일정 → 담당 → 완료 증빙. 실행 가능한 일정으로 쓴다.

### 5. 하위 협력사 전달
고객 행동규범 준수를 하위 협력사에 요청하는 안내문과 확인서 양식.

## 출력

요청에 맞는 문서를 마크다운으로 만들고, 고객 양식(엑셀 설문)이 있으면 그 파일에 답변을 채운 사본을 만든다.

## 주의

- 해외 법규(EU 공급망 실사 관련 규정 등)는 개정·적용 시점이 바뀌므로 언급할 때 최신 공식 자료로 확인하라고 적는다.
