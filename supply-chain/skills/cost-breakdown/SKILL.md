# /cost-breakdown

> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

## 받을 데이터

- BOM(자재별 소요량·단가·스크랩률)
- 공정별 작업 시간, 시간당 노무비·경비율 (회사 기준)
- 관리비율·이윤율 (회사·고객 계약 기준)
- 고객 지정 원가 계산서 양식(있으면 그 양식대로)

모든 비율과 단가는 사용자 값만 쓴다. 업계 평균값을 가정해 넣지 않는다.

## 계산 (코드로 실행)

- 재료비 = Σ(소요량 × 단가 × (1 + 스크랩률))
- 가공비 = Σ(공정 시간 × 시간당 노무비) + 경비
- 관리비·이윤 = 계약·회사 기준 비율 적용
- 합계와 항목별 비중

## 용도별 출력

1. **원가 계산서**: 항목별 표와 비중 그래프
2. **원자재 변동 단가 조정 근거**: 기준 시점·현재 시세, 해당 원자재 사용량, 단가 영향액. 시세 출처와 기준일을 반드시 적는다. 연동 공식이 계약에 있으면 그 공식만 쓴다
3. **설계변경 원가 변동**: 변경 전·후 BOM·공정 비교, 증감 내역
4. **견적 비교**: 업체별 항목 비교, 차이가 큰 항목과 확인 질문

## 출력 형식

```markdown
## 원가 분석: [품번] — [용도]
### 가정값
| 항목 | 값 | 출처 |
### 원가 구성
| 구분 | 금액 | 비중 |
### 변동 근거 / 비교
```

## 주의

- 원가 자료는 기밀이다. 고객 제출용과 내부 검토용을 구분해 만든다.
- 하위 협력사에 원가 자료를 요구하는 문서를 만들 때는 하도급 관련 법규와 회사 규정을 확인하라고 적는다.
