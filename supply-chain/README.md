# 구매·공급망 플러그인 (`supply-chain`)

구매·공급망 업무 — 하위 협력사 평가·선정, 납입 성과·결품 조기 경보, 공급망 ESG 자가진단·실사 대응, 원가 계산서와 단가 조정 근거.

고객 요구사항을 하위 공급망까지 전달하고 납입·원가·ESG를 관리하도록 돕는다.

> 현대자동차·기아와 무관한 비공식 플러그인이다. 제도 관련 수치는 [HKMC-FACTS.md](HKMC-FACTS.md)의 공개 자료(기준 시점 표기)를 근거로 하며, 고객사가 배포한 최신 기준서가 항상 우선한다.

## 설치

```bash
claude plugin marketplace add <이 저장소 경로 또는 GitHub 주소>
claude plugin install supply-chain@hkmc-supplier-plugins
```

Claude 데스크톱 앱에서는 플러그인 메뉴에서 이 폴더(또는 압축 파일)를 추가한다.

## 스킬

| 명령 | 하는 일 |
|---|---|
| `/cost-breakdown` | 부품 원가를 재료비·가공비(노무비·경비)·관리비·이윤으로 나눈 원가 계산서를 만들고, 원자재 시세 변동(예: 동·수지)·설계변경·물량 변동에 따른 단가 조정 근거와 견적 비교표를 정리한다. |
| `/delivery-performance` | 고객 납입 성과(납기 준수율, 결품, 긴급 오더, 재고 일수)를 분석하고, 결품 위험 조기 경보와 결품 발생 시 대응 계획·고객 보고서를 만든다. |
| `/sub-supplier-evaluation` | 하위 협력사(원자재·부품·임가공 업체)를 신규 선정하거나 정기 평가한다. |
| `/supplier-esg` | 고객사(완성차·1차 협력사)의 공급망 ESG 평가·자가진단·실사 요청에 대응한다. |

스킬은 관련 요청을 하면 자동으로 쓰이고, 명령(`/supply-chain:스킬이름`)으로 직접 부를 수도 있다.

## 연결 도구

연결 없이 파일 첨부와 대화만으로 작동한다. 그룹웨어·MES·ERP·고객 포털을 연결하면 자료를 직접 가져온다. 자리표시자(`~~groupware` 등)의 뜻은 [CONNECTORS.md](CONNECTORS.md)를 본다. 회사 시스템 이름으로 바꾸려면 `supplier-plugin-builder` 플러그인의 `/customize-for-company`를 쓴다.

## 공통 원칙

- 규격값·기준값은 고객 도면·규격·사양서와 회사 기준에서만 가져오고, 없으면 "확인 필요"로 남긴다.
- 계산은 코드로 실행해 검산한다.
- 고객 도면·단가·개인정보는 회사 정보보안 규정이 허용하는 범위에서만 첨부한다.
