# 현대·기아 협력사 제도 기초 사실 (검증 메모)

> 이 파일은 공개 자료로 확인한 사실만 담는다. 각 항목에 **기준 시점과 출처**를 붙였다.
> 점수, 등급, 기간 같은 수치는 바뀔 수 있으므로 **고객사(1차 협력사 또는 현대·기아)가 배포한 최신 기준서가 항상 우선**한다.
> Claude는 이 파일의 수치를 인용할 때 반드시 "공개 자료 기준(시점), 최신 기준서로 확인 필요"라고 함께 적는다.
> 이 플러그인 모음은 현대자동차·기아와 무관한 비공식 자료다.

## 1. 협력사 품질 평가 제도의 두 축

| 구분 | 품질 5스타 제도 | SQ 인증 제도 |
|---|---|---|
| 대상 | 현대·기아 **1차 협력사** | **2·3차 협력사** (1차 협력사 납품 조건으로 활용) |
| 도입 | 2002년 | 2016년 기사 시점에 운영 중으로 보도 |
| 평가 부문 | 품질·기술·납입 3개 부문, 별 1~5개 | 업종별 공정 품질관리 능력 (단일 인증, 등급제 아님으로 보도) |
| 합격선 | 품질5스타 85점 이상, 그랜드 품질5스타 90점 이상(2009년 신설) — 2014년 기사 기준 | 75점 이상 인증, 60~74점 육성 후 재심사 — 2016년 기사 기준 |
| 주기 | 반기 평가(7월 말·12월 말), 재심사로 갱신 — 2014년 기사 기준 | 신청 접수 후 약 90일 내 결정 — 2016년 기사 기준 |

**SQ 인증 대상 업종 12개** (2016년 기사 기준): 고무성형, 배합고무, 도장, 도금, 봉제, 전기전자, **와이어링**, 사출금형, 용접, 주·단조, 열처리, 납땜.

**5스타 실무 지표** (블로그 정리, 비공식): 품질(불량률, 고객 클레임, 공정불량, 개선대책서, 재발방지), 기술(VA/VE, 원가절감 제안, 신차 개발 대응, 공법 개선), 납입(납기 준수율, 결품 관리, 긴급오더 대응, 재고 운영).

**SQ 업종별 확인 포인트 예** (블로그 정리, 비공식): 전장부품 — 회로·기능검사, ESD, 신뢰성시험, 소프트웨어 변경관리 / 기타 공정 — 작업표준, 검사기준, 숙련도, 불량품 격리.

## 2. 신차 개발 이벤트 (용어는 차종·조직마다 다름)

현직자 답변 기준의 일반적 순서: 모델확정 → 시작차(T카) → 시제차(Proto) → P1·P2(파일럿) → 선행양산(M, MP) → 양산(SOP).
정확한 명칭과 일정은 프로젝트별 개발 일정표로 확인한다.

## 3. 초도품 승인 용어와 국제 공통 품질 도구

- **현대·기아 공급망 용어**: 초도품 승인은 **ISIR**(Initial Sample Inspection Report)이라고 부른다 (현업 확인, 2026-10-28). 결과물에서는 ISIR을 기본 용어로 쓰고, PPAP는 해외 고객이 요구할 때만 쓴다
- **ISIR 서류 구성**은 1차 협력사·완성차가 지정한 목록을 따른다. 아래 PPAP 요소는 서류 누락을 점검할 때 참고하는 국제 기준이다
- **APQP 5단계**: ① 계획·정의 ② 제품 설계·개발 ③ 공정 설계·개발 ④ 제품·공정 유효성 확인 ⑤ 피드백·평가·시정조치
- **PPAP 18개 요소 (AIAG, 해외 고객용)**: 설계기록, 승인된 설계변경 문서, 고객 엔지니어링 승인, DFMEA, 공정흐름도, PFMEA, 관리계획서, MSA, 치수 결과, 재료·성능 시험 결과, 초기 공정 연구(Cpk/Ppk), 공인 시험기관 문서, 외관 승인 보고서(AAR), 샘플 제품, 마스터 샘플, 검사 보조구, 고객 특정 요구사항 준수 기록, PSW
- **PPAP 제출 레벨 1~5**: 1 PSW만 / 2 PSW+제한된 데이터·샘플 / 3 전체 데이터·샘플(기본) / 4 고객 지정 / 5 공급사 현장 검토
- **ISIR**: 초도 샘플의 치수·재질·기능 검사 보고서. 승인·조건부 승인·보류 판정
- **4M**: Man(사람), Machine(설비), Material(재료), Method(방법). 실무에서 Measurement·Environment를 더해 4M1E/5M1E로 쓰기도 한다
- **FMEA**: AIAG-VDA FMEA 핸드북(2019) 7단계 — 계획·준비, 구조 분석, 기능 분석, 고장 분석, 리스크 분석(조치 우선순위 AP: High/Medium/Low), 최적화, 결과 문서화

## 4. 현대·기아 관련 고객 특정 요구사항(CSR) 예

1차 협력사가 하위 협력사에 배포한 현대·기아 CSR 부록(2020년 개정본, 공개 문서)에서 확인된 항목:
- 작업 셋업 검증: 초물, 재료 교체, 공구 교체, 계획·비계획 정지 후 조건 확인
- 외부 제공품 검증: 법규 적합 증빙, 수입검사·정기검사 절차
- 합격 기준: 공정 순회검사, 부적합품 식별·격리, 한도 견본·마스터 샘플 관리, 감성 품질(조작감·소음) 마스터 관리
- 고객 불만·필드 불량 분석: NTF(문제 미발견) 포함 불량 분석 프로세스, 국내외 필드 클레임 정보 수집, 해외공장·CKD 불량 포함, 불량품(구품) 보관
- 하위 공급망 전체에 요구사항 전달

## 5. 공급망 ESG (현대자동차 공개 FAQ 기준)

- 현대자동차와 계약한 협력사는 협력사 행동규범을 준수해야 하며, 거래업체(하위 공급망)에도 준수를 권장해야 한다
- 협력사 ESG 평가로 리스크를 진단하고, 고위험 협력사에는 개선조치 또는 개선계획 수립을 요구한다
- 협력사는 현대자동차가 직접 또는 제3자를 통해 실시하는 ESG 진단·실사에 대응해야 한다
- 업계 세미나 자료 기준으로 2·3차 협력사에도 ESG 문서 제출·실사 참여 요청이 확대되고 있다
