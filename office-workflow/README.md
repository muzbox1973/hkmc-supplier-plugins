# 사무·그룹웨어 플러그인 (`office-workflow`)

사무 업무 — 전자결재 기안문·품의서, 주간·월간 보고, 회의록과 조치 사항, 고객사 메일·공문 회신, 해외 사업장 다국어 커뮤니케이션.

그룹웨어로 일하는 제조사 사무직의 문서 작성 시간을 줄인다.

> 현대자동차·기아와 무관한 비공식 플러그인이다. 제도 관련 수치는 [HKMC-FACTS.md](HKMC-FACTS.md)의 공개 자료(기준 시점 표기)를 근거로 하며, 고객사가 배포한 최신 기준서가 항상 우선한다.

## 설치

```bash
claude plugin marketplace add <이 저장소 경로 또는 GitHub 주소>
claude plugin install office-workflow@hkmc-supplier-plugins
```

Claude 데스크톱 앱에서는 플러그인 메뉴에서 이 폴더(또는 압축 파일)를 추가한다.

## 스킬

| 명령 | 하는 일 |
|---|---|
| `/approval-draft` | 그룹웨어 전자결재용 기안문을 쓴다. |
| `/customer-letter` | 고객사(1차 협력사·완성차)에 보내는 업무 메일과 공문 회신을 쓴다. |
| `/global-site-comms` | 본사와 해외 사업장(중국·베트남·멕시코·인도 등) 사이의 업무 지시, 품질 공유, 표준 전개 문서를 대상 언어로 쓰거나 번역한다. |
| `/meeting-minutes` | 회의 녹취·메모를 회의록으로 정리한다. |
| `/weekly-report` | 부서·개인의 주간·월간 업무 보고서를 만든다. |

스킬은 관련 요청을 하면 자동으로 쓰이고, 명령(`/office-workflow:스킬이름`)으로 직접 부를 수도 있다.

## 연결 도구

연결 없이 파일 첨부와 대화만으로 작동한다. 그룹웨어·MES·ERP·고객 포털을 연결하면 자료를 직접 가져온다. 자리표시자(`~~groupware` 등)의 뜻은 [CONNECTORS.md](CONNECTORS.md)를 본다. 회사 시스템 이름으로 바꾸려면 `supplier-plugin-builder` 플러그인의 `/customize-for-company`를 쓴다.

## 공통 원칙

- 규격값·기준값은 고객 도면·규격·사양서와 회사 기준에서만 가져오고, 없으면 "확인 필요"로 남긴다.
- 계산은 코드로 실행해 검산한다.
- 고객 도면·단가·개인정보는 회사 정보보안 규정이 허용하는 범위에서만 첨부한다.
