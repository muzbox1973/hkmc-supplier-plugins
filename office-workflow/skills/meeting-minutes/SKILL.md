# /meeting-minutes

> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

## 작성 원칙

- 발언 순서대로 받아 적지 않고 **안건별**로 정리한다
- 결정 사항, 조치 사항, 미결 사항을 섞지 않는다
- 조치 사항은 "누가 / 무엇을 / 언제까지"가 모두 있어야 한다. 빠지면 "[담당 미정]"처럼 표시해 회의 후 확정하게 한다
- 숫자·날짜·품번은 원문 그대로. 불분명하면 "[확인 필요]"
- 고객 회의록은 고객과 우리 회사 의무를 구분하고, 합의되지 않은 내용을 합의처럼 쓰지 않는다

## 형식

```markdown
## 회의록: [회의명]
| 일시 | | 장소 | | 작성 | |
| 참석 | |

### 안건별 논의 요약
### 결정 사항
1.
### 조치 사항
| No | 내용 | 담당 | 기한 |
### 미결 사항
### 다음 회의
```

## 후속 작업 제안

- 조치 사항 알림 메일 초안
- 고객 회의면 상호 확인 요청 메일 초안

## 연결 도구가 있으면

- **~~email**: 회의록 배포 메일 초안을 만든다(발송은 사용자 확인 후).
- **~~groupware**: 회의록 게시판 양식으로 바꾼다.
