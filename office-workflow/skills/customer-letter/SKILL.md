# /customer-letter

> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

## 작성 원칙

- 첫 문단에 목적을 쓴다(회신 / 통보 / 요청)
- 사실 → 우리 조치 → 고객에게 요청 → 다음 일정 순서
- 책임 인정·비용 부담·보증처럼 법적·금전적 의미가 있는 표현은 쓰지 않고, 필요하면 사용자에게 내부 확인을 받으라고 표시한다
- 확인되지 않은 원인이나 날짜를 약속하지 않는다
- 과한 사과 반복 없이, 정중하고 짧게

## 형식

메일:
```
제목: [회사명] [품번/건명] [목적] 건

○○○ 책임님께,

[목적 한 문장]

1. 현황
2. 조치 내용
3. 요청 사항
4. 향후 일정

[서명]
```

공문 회신이면 수신·참조·제목·관련 문서(상대 공문 번호·일자)·본문·붙임·끝 형식을 쓴다.

## 변형 제공

상황이 민감하면(지연·불량 통보) 표현 강도가 다른 두 가지 초안(사실 중심 / 관계 배려)을 함께 준다.
