# /global-site-comms

> 낯선 자리표시자나 연결된 도구는 [CONNECTORS.md](../../CONNECTORS.md)에서 확인한다.

## 진행

1. 대상 사업장·언어·독자(현지 관리자 / 현장 작업자 / 현지 고객)를 확인한다. 멕시코는 스페인어, 인도는 영어 또는 힌디어 등 사업장에서 실제 쓰는 언어를 묻는다
2. 회사 용어집이 있으면 받는다. 없으면 이번 문서에서 쓴 전문 용어 대조표(한국어 ↔ 대상 언어)를 결과에 붙여 다음에 재사용하게 한다
3. 원문을 짧은 문장으로 다듬은 뒤 번역한다 (주어 생략, 이중 부정, 한국식 완곡 표현 정리)
4. 숫자·단위·품번·날짜 형식은 그대로 두고, 날짜는 오해 없게 YYYY-MM-DD로 쓴다

## 출력

- 한국어 원문(다듬은 판)과 번역문 병기
- 용어 대조표
- 현지 확인이 필요한 부분 표시 (안전·법규 관련 문구, 문화적으로 민감한 표현)

## 주의

- 번역본은 현지 담당자 검토를 거쳐 쓰라고 적는다. 특히 작업 안전 지시는 현지 검토 필수.
- 현지 노동·안전 법규에 관한 문장은 현지 기준 확인 항목으로 둔다.
